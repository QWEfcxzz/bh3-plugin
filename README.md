面向 Yunzai / TRSS-Yunzai 的崩坏3（Honkai Impact 3rd）查询插件，支持战绩查询与公开图鉴查询。

## 功能

| 命令 | 说明 |
| --- | --- |
| `#崩坏3绑定 <UID>` | 绑定自己的游戏 UID |
| `#崩坏3切换 <UID>` | 切换当前查询 UID |
| `#崩坏3当前` | 查看当前绑定的 UID |
| `#崩坏3解绑` | 解除绑定 |
| `#崩坏3cookie <Cookie>` | （仅主人）配置默认 Cookie |
| `#崩坏3cookie <UID> <Cookie>` | （仅主人）为指定 UID 配置 Cookie |
| `#崩坏3面板` | 总览：等级、收藏、深渊、战场、逐光 |
| `#崩坏3便笺` | 体力、训练值、活动奖励 |
| `#崩坏3角色` | 角色大头像列表 |
| `#崩坏3角色 <角色名>` | 喵喵风格角色面板（大头像/装备/六维） |
| `#崩坏3深渊` | 超弦空间 + 量子奇点战绩 |
| `#崩坏3战场` | 记忆战场战绩 |
| `#崩坏3逐光` | 往世乐土战绩 |
| `#崩坏3图鉴 <关键词>` | 图鉴搜索（公开接口） |
| `#崩坏3角色图鉴 <名字>` | 角色图鉴 |
| `#崩坏3武器图鉴 <名字>` | 武器图鉴 |
| `#崩坏3圣痕图鉴 <名字>` | 圣痕图鉴 |
| `#崩坏3图鉴详情 <编号>` | 查看指定条目详情 |
| `#崩坏3角色图 <名字/别名>` | 角色立绘 + 背景图 + 角色档案（六维评价） |
| `#崩坏3立绘 <名字/别名>` | 同上 |
| `#崩坏3伤害 <角色> [攻击] [倍率%] [增伤%] [暴击率%] [暴伤%] [防御]` | 伤害估算（攻击省略自动用图鉴基础攻击） |
| `#崩坏3角色列表` | 内置 110 名女武神清单 |
| `#崩坏3帮助` | 爱莉希雅主题帮助图 |
| `#崩坏3帮助文本` | 纯文本帮助 |

前缀 `崩坏3`、`崩三`、`bbb` 均可使用。战绩查询命令默认使用绑定的 UID，也可临时附加 UID（如 `#崩坏3面板 100000001`）。

## 图片输出

所有查询结果均以图片卡片形式输出（粉紫渐变 + 磨砂玻璃风格）：

- 深渊 / 记忆战场 / 往世乐土：角色大头像 + 名字 + 星级卡片展示阵容
- 角色面板：仿喵喵插件原神面板的大头像 + 武器/圣痕/人偶装备卡 + 六维评价
- 有链接的结果（WIKI 等）会在图片后附带可点击的链接文本

## Cookie 来源（优先级）

1. `#崩坏3cookie <UID> <Cookie>` 配置的专用 Cookie
2. `#崩坏3cookie <Cookie>` 配置的公共 Cookie
3. **逍遥插件（xiaoyao-cvs-plugin）已获取的 CK** —— 自动从共享数据库读取，使用拥有该 UID 的账号 CK

## 重要限制

米游社崩坏3战绩接口**仅允许查询 Cookie 所属账号本人的号**（跨账号查询会返回“用户信息不匹配”）。因此：

- 群友想查自己的面板：先用逍遥插件登录自己的米游社账号（该号需有崩坏3角色），之后直接发自己的 UID 即可查询，无需在崩坏3插件里配置任何东西。
- 无法查询其他人的号（官方接口限制，非插件限制）。
- 若目标 UID 没有对应已登录的米游社账号，插件会明确提示原因。

## 角色数据库

插件内置 110 名女武神数据库（来自米游社公开图鉴，`data/characters.json`），每名角色包含：

- 别名（如 炎律→薪炎之律者、黑希→彼岸双生、火符→浮生·渡尘之羽）
- 元素（物理/火/冰/雷）、属性（生物/异能/机械/量子/虚数/星尘）、初始阶级
- 角色立绘（竖版）、背景图（横版）、头像
- 六维评价（持续输出/爆发输出/爆发速度/控制/生存/辅助）

所有支持角色的命令（角色图、伤害计算、角色面板、图鉴）都支持别名匹配。

## 伤害计算说明

`#崩坏3伤害` 使用简化公式估算：

```
伤害 = 攻击力 × 技能倍率 × (1+增伤) × (1+易伤) × (1-抗性) × 暴击期望
物理角色额外乘 (1 - 防御/(防御+2000))
```

默认参数：倍率 100%、增伤 0%、暴击率 100%、暴伤 150%。结果为估算值，未计入队友增益、易伤、穿透与实际技能倍率，请以游戏内为准。

## 帮助图

`#崩坏3帮助` 会渲染一张爱莉希雅（粉色妖精小姐♪）主题的帮助图：横版立绘为背景、竖版立绘作装饰，命令按模块分类展示。若本机 Puppeteer 渲染失败会自动回退为纯文本帮助。

## 数据来源

- 战绩查询：米游社崩坏3 战绩接口（`api-takumi-record.mihoyo.com/game_record/app/honkai3rd/api`），需要绑定米游社 Cookie。
- 图鉴查询：米游社崩坏3 公开图鉴接口（`api-takumi-static.mihoyo.com/common/blackboard/bh3_wiki`），无需 Cookie。

## Cookie 获取

1. 浏览器登录 https://www.miyoushe.com
2. F12 打开开发者工具，在 Network 中找到任意请求，复制请求头中的完整 `Cookie` 字段值
3. 私聊/群聊对 Bot 发送 `#崩坏3cookie <粘贴的Cookie>`（仅主人可用）

> 注意：Cookie 包含账号凭据，仅建议主人在自己的机器人上配置，不要泄露给他人。米游社可能对频繁请求触发验证码风控（retcode 1034），此时请稍后再试。

## 安装

### 方式一：Git 克隆（推荐）

在 Yunzai 根目录执行：

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git ./plugins/bh3-plugin
```

### 方式二：手动解压

将压缩包解压到 Yunzai 的 `plugins/bh3-plugin` 目录。

### 安装依赖

进入插件目录安装依赖（任选一种）：

```bash
cd plugins/bh3-plugin
npm install
```

或使用 pnpm：

```bash
cd plugins/bh3-plugin
pnpm install
```

依赖说明：

- `sqlite3`：读取逍遥插件（xiaoyao-cvs-plugin）/喵喵共享数据库中的米游社 CK，实现"群友只发 UID 即可查询自己的面板"。未安装时插件仍可用，但只能通过 `#崩坏3cookie` 手动配置 Cookie。
- `puppeteer`（可选）：用于渲染爱莉希雅主题帮助图。未安装时 `#崩坏3帮助` 自动回退为纯文本。

要求 Node.js >= 18（插件使用全局 `fetch`）。

### 更新角色数据库

新版本女武神发布后可重新抓取图鉴数据：

```bash
cd plugins/bh3-plugin
npm run update:data
```

最后重启 Bot 即可使用。
